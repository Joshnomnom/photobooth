## Conventions

- **Plan items** use checkboxes. Tick them in the same commit as the work.
- **Decisions** go in the *Decision log* at the bottom of `PLAN.md`, with the date and the reason.
- **Research** notes cite their sources inline. Mark anything not verified as *(unverified)*.
